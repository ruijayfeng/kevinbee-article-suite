# 凯冰文章校准库

把修改好的 `.md` 或 `.txt` 文章交给我，或放到 `calibration/inbox/` 并告诉我文件名。我交你审阅时会自动保存修改前稿；你不需要再找或上传它。我会对比两版，先把你的修改版保存为候选。你明确说“这版可以作为以后参考”后，它才会移入 `calibration/approved/`。

如果能告诉我你最在意的一处改动，会更方便复盘；只交修改版也可以。对于这个机制上线前的历史文章，我会先从已有项目稿件找前稿；找不到也能收录终稿，但不会猜测你的修改理由。以后每篇新文章会先看题材是否相近，最多参考两篇已认可文章。外部作者范文不会混入你的个人样本库。

模型评审负责找出具体段落的问题和改动规律。是否收录、是否修改 Skill、哪一版算好稿，由你的选择决定。历史版本会保留，改错可以撤回。

小红书也可以交回逐页文案和配文的修改版。套件先保存包含两者的审阅稿，快照记录 `xiaohongshu` 平台，修改版候选继承它。收到修改后同步回分页文案和配文；需要改图片时另做新候选并核验。以后最多参考两份同平台、题材相关且复盘完成的认可文案；旧文章没标平台时不猜测，不自动带入小红书参考。认可文案不等于认可图片，视觉参考继续由小红书 Skill 管理。
