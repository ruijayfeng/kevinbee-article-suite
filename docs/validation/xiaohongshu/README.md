## 自动验证

从套件根目录运行 README 中的验证命令。新增测试覆盖：

- 规划、封面、整套、未完成样张；缺页、重复页序、缺图、缺提示词、错误尺寸与待补内容。
- 非法或损坏 PNG、无效生成记录、无效旧核验报告，以及图片与提示词重复使用。
- 文案改动后旧报告失效，受影响页面须更新提示词和图像；配文修改只要求同步审阅稿与重新核验。
- 视觉检查默认未完成；文件检查不会自动代表中文、人物、证据与手机阅读通过。
- 小红书快照平台继承、冲突拒绝、直接收录、旧元数据兼容及按平台筛选。
- 原公众号、知乎交接和写作基线不变。

自动测试使用临时合成 PNG 和明确标为测试夹具的记录，不调用图像工具。首次真实制作仍需验收封面、含角色内页、证据页、中文字形、人物身份与手机阅读；检查通过后由用户审查并发布。
