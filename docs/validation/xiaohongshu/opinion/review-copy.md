# 小红书审阅稿

## 第 1 页

- Title: 删掉条件，结论也会变
- Point: 把长文转成图文，先保留决定结论的条件。

## 第 2 页

- Title: 结论与依据放在一起
- Point: 输入材料、测试步骤、使用环境可能影响观察结果。
- Point: 不要把局部观察写成普遍能力。

## 第 3 页

- Title: 从重复解释里省空间
- Point: 可以删除重复总结。
- Point: 关键限制和失败仍要留在读者能看到的位置。

## 发布标题、配文与话题

# 发布标题

删掉条件，结论也会变

# 配文

图文的篇幅有限，但不能只留下原文里最醒目的结论。例如同一个工具的效果可能依赖输入材料、测试步骤和使用环境。删去这些条件，读者会把局部观察理解成普遍能力。我的看法是，转成图文时先留下决定结论的条件，再删重复解释。这里讨论编辑取舍，没有个人实测或性能数字。
