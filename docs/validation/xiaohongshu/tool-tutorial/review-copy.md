# 小红书审阅稿

## 第 1 页

- Title: 先准备材料，再安排页面
- Point: 原始笔记、已有文章和真实截图都可以作为输入。
- Point: 先说明读者要解决什么问题。

## 第 2 页

- Title: 原文的条件也要留下
- Point: 文章转图文时，保留影响结论的条件、失败和限制。
- Point: 截图与概念示意分别标记。

## 第 3 页

- Title: 出图前先复核文字
- Point: 小红书 Skill 决定分页和逐页文案。
- Point: 写作 Skill 用基础规则检查事实、人称和夸张表达。

## 第 4 页

- Title: 检查完整交付
- Point: 按计划页数检查独立图片和提示词。
- Point: 最终图为 1080×1440，逐字核对并检查手机阅读。
